# YMM43D

ゆっくりMovieMaker4 に 3D 空間を足すプラグインです。

図形・エフェクト・アイテムのすべてが 1 つのワールド座標に並ぶので、**アイテムをまたいだ前後関係が正しく出ます**。上のレイヤーが必ず手前になる、ということがありません。

カメラ・光源・環境はタイムライン上のアイテムとして置きます。ふつうのアイテムと同じように中間点を打てるので、値を時間で動かせます。

## 追加されるもの

### 図形

| 名前 | 内容 |
|---|---|
| 3Dアイテム | 平面・正多面体5種（四〜二十面体）・球・円柱・円錐・ドーナツ。面ごとの塗り分けができます |
| 3Dモデル | `.obj` / `.gltf` / `.glb` / `.vrm` / `.fbx` のモデルを読み込みます。骨の付いたモデル（VRM・FBX など）は、骨ごとに回転を付けてポーズを作れます。材質の色と画像も一緒に読み、材質ごとにテクスチャを選び直せます。mtl の画像が見つからないときは、モデルのフォルダとその下（2階層まで）から同じ名前の画像を探します |
| ビームライト3D | 舞台照明のような光の筋。当たった物も明るくします |
| ノイズ3D | 幅・高さ・奥行きで決めた箱の中だけに、3D のノイズで霧やもやを出します。種類や濃淡・フラクタル・歪み・移動は YMM4 の「ノイズ」と同じ項目です |
| リキッドグラス3D | 3D 空間に置くガラスの塊（角丸の箱・球）。向こうにある 3D の物が、屈折・すりガラス・色収差つきで透けて見えます |

### 映像エフェクト

| 名前 | 内容 |
|---|---|
| 3D空間に置く | ふつうの 2D アイテムを板として 3D 空間に置きます。3軸の回転も掛かります |
| 立体化3D | 画像の形をそのまま奥行き方向へ押し出します |
| 点群3D | 画像を格子状の粒・線・面に分解します。波・ねじれ・膨らみ・球への巻き付けができます |
| 湾曲3D | 板を弧に曲げ、同時にねじります |
| 波打ち3D | 板を波の形にうねらせます。中心から広がる波紋にもできます |
| 折る3D | 板を蛇腹に折り畳みます |
| 砕け散る3D | 板を破片に割って飛ばします。どこから当たったかを 3D で決められます |
| ランダム配置3D | アイテムを複製して、X・Y・Z で決めた範囲の 3D 空間にばらまきます。回転・大きさのばらつき・移動・回転の速さ、カメラに向けるを選べます。複製どうしや他の物との前後関係、光、影が効きます。3Dアイテム・3Dモデル・リキッドグラス3D などの 3D の図形に付けると、板ではなく立体のまま複製します |
| 縁取り3D | YMM4 の「縁取り」と同じ設定で、3D の物の見えている輪郭に縁を付けます。縁は物のすぐ後ろの奥行きに描かれるので、手前の物に正しく隠れます |

### タイムラインアイテム

| 名前 | 内容 |
|---|---|
| 3Dカメラ | 位置と向き。置いた区間だけ効き、レイヤー番号がいちばん大きいものが使われます |
| 3D光源 | 平行光・点光源・スポットライト。置いた分だけ足し合わさります（数に上限はありません）。影も落とせます |
| 3D環境 | 環境光と霧、影の細かさ。レイヤー番号がいちばん大きいものが使われます |

### ツールウィンドウ

**3Dプレビュー**。シーンを好きな視点から確認でき、アイテムを直接掴んで動かせます。

## 使い方

### 2D のアイテムをカメラに乗せる

テキストや画像は YMM4 が 2D のまま描くので、そのままではカメラの影響を受けません。**「3D空間に置く」を付けると、他の 3D 物体と同じ扱いになります。** テキストの「文字ごとに分割」を入れたときは、1文字ずつ別の板になります。

まとめて乗せたいときは、**エフェクトアイテム**に付けてください。下のレイヤーを合成した絵に掛かるので、1 つ置くだけでその下すべてが 1 枚の板としてカメラに乗ります（そのかわり、アイテムごとの前後関係は失われます）。**この乗せ方は動画出力にだけ現れます。** 3Dプレビューは合成前のアイテムを1つずつ描くので、そちらではアイテムが別々に見えます。

**エフェクトアイテムの図形（マスク）は、画面全体を覆う大きさにしてください。** エフェクトアイテムのエフェクトは図形の中にしか掛からないので、既定の小さな四角形のままだと、その外に元のアイテムが残って二重に見えます。これは YMM4 標準のエフェクトでも同じです。板の外側は黒で埋まります（エフェクトアイテムがエフェクトに渡す絵の背景と同じ色です）。

アイテムの種類ごとに既定にすることもできます。エフェクトを付けたアイテムを YMM4 の「デフォルトのアイテム」として保存すると、以後その種類の新しいアイテムに最初から付きます。

### まとめて動かす（グループ制御）

いくつかのアイテムをまとめて動かしたいときは、**グループ制御**に入れてください。グループ制御の位置・Z・画面内の回転・拡大率は、中の 3D のアイテムに親として 3D のまま掛かります。

**縦や横に回したいときは、グループ制御に「3D空間に置く」を付けます。** 中のアイテムが持っている立体や板はそのまま保たれ、回転はグループ制御の中心を軸にして、まとまり全体に掛かります。壁や床を並べて部屋を作り、部屋ごと回す、といった使い方ができます。

- 中のアイテムが 2D のときは、これまでどおり板として置かれます。
- グループ制御に 3D エフェクトを重ねて付けたときは、前のエフェクトの結果に後のエフェクトが掛かります。「3D空間に置く」と「縁取り3D」を並べれば、まとまりごと回しながら輪郭に縁を付けられます。
- このとき「3D空間に置く」の陰影・つや・他のものを隠すは、中のアイテムが 3D を持っている場合は使われません。中のアイテム側の設定が効きます。

### カメラ

カメラアイテムが無い区間は、原点を正面から見る既定のカメラになります。

画角は既定では、**カメラから 1000px 離れた面が画面とちょうど 1 対 1 で写るように**決まります。このため既定の位置に置いたカメラでは、Z = 0 のアイテムが YMM4 の 2D と同じ位置・大きさに写ります。「視野角変更」を入れると自分で決められます。

置き方は3つあります。

| 置き方 | 決め方 | 向いている使い方 |
|---|---|---|
| **注目**（既定） | 置く場所 + 見つめる点 | 被写体を追う |
| 位置 | 置く場所 + 水平・垂直の回転角 | カメラを手で持つように振る |
| 回り込み | 見つめる点 + 距離 + 水平・垂直の回転角 | 被写体のまわりを回す |

**「回り込み」は、YMM4 の「回り込みカメラ」と同じ決め方です。** ただしこちらは本物の 3D 空間のカメラなので、3D の図形もエフェクトも 2D のアイテムも、まとめて正しい前後関係のまま回り込みます。中間点を打てば、距離や角度を時間で動かせます。

### 光

光源アイテムを 1 つも置かなければ、**左上手前からの平行光と環境光**が当たります。この既定値は、カメラを正面から向いた面がちょうど明るさ 1 になるように選んであります。2D の絵を「3D空間に置く」だけのときに暗くならないためです。

陰影を掛けたくないものは、各エフェクトと図形の「陰影をつけない」を入れてください。

光源は**何個でも置けます**。ただし画素ごとに全灯を計算するので、増やした分だけ重くなります。

「影を落とす」を入れると、**光をさえぎった物の後ろが暗くなります**。平行光・スポットライト・点光源のどれでも落とせます。1 灯ごとに場をもう一度描くので、増やすと重くなります。**点光源は全方向を見るため、1 灯で 6 面ぶん描きます**（平行光やスポットの 6 倍の重さ）。同時に使える板は 24 枚までで、平行光・スポットは 1 枚、点光源は 6 枚使います。

影のふちは、光源ごとの「影のぼかし」でやわらかくできます。影の粗さが気になるときは、**3D環境の「影の細かさ」**を上げてください（512〜4096。上げるほど GPU のメモリを使います）。

つやのある見た目にしたいときは、図形やエフェクトの「つや」を上げてください。光の映り込みが点として乗ります。「つやの鋭さ」を上げるほど、映り込みが小さく締まって金属やプラスチックのように見えます。

影は**絵の形どおりに落ちます**。文字や切り抜き画像を「3D空間に置く」と、四角ではなく文字の形の影になります。

**光の筋そのものを見せたいときは、図形の「ビームライト3D」を使ってください。** 舞台のビームのように、埃っぽい空気の中を光が通っていく見た目になります。「まわりを照らす」を入れておくと、見えている円錐とぴったり同じ形で物も明るくなります。物の後ろに回れば筋も隠れます。

### ガラス（リキッドグラス3D）

図形の「リキッドグラス3D」は、**3D 空間に置けるガラスの塊**です。向こうにある 3D の物が、ふちで曲がり、少しぼけて見えます。

- 形は「角丸の箱」と「球」。角丸の箱は「角の丸み」を上げるほど、ふちが丸くなって像が大きく曲がります。球は「直径」で大きさを決め、レンズのように向こうの像が逆さに写ります。
- 「屈折率」で曲がり方、「向こうまでの距離」でふちの像のずれ幅、「すりガラス」でぼけ具合を決めます。
- **ガラス越しに見えるのは 3D の物だけです。** 3D の図形・3D モデル・「3D空間に置く」などを付けたアイテムは透けて見えますが、3D になっていない 2D のアイテムは曲がらずにそのまま見えます。背景の画像も曲げたいときは「3D空間に置く」を付けてください。
- レイヤーの順番は気にしなくて大丈夫です。ガラスの向こうの物は、それぞれのアイテムを描くときにガラスの形で削られ、ガラスの中に曲がって写ります。
- ガラスは影を落としません。
- ガラス 1 枚ごとに、向こうのシーンをもう一度描き直すので、ガラスや 3D の物を増やすと重くなります。ガラス越しにガラスは見えません。

### 縁取り（縁取り3D）

映像エフェクトの「縁取り3D」は、**カメラから見えている物の輪郭**に縁を付けます。縁も 3D 空間の中に描くので、動画出力でも 3Dプレビューでも同じように見え、手前の物には隠れます。

- 設定は YMM4 の「縁取り」と同じです（太さ・ぼかし・品質・なめらかさ・縁のみ・角縁取り・X・Y・不透明度・拡大率・回転角・縁の模様）。
- 3D の図形・3D モデルに付けると、その立体の輪郭に縁が付きます。**「立体化3D」などほかの 3D エフェクトの後ろに付ける**と、その結果の立体に縁が付きます。ふつうの 2D アイテムに付けたときは、「3D空間に置く」と同じく板として置いて、その形に縁を付けます。
- **グループ制御に付けると、中のアイテムそれぞれに縁が付きます。** 立体化3D を付けた画像や 3D の図形がまざっていても、それぞれの立体の輪郭に付きます。3Dプレビューにも出ます。
- リキッドグラス3D のように透けて見える物は、中まで塗らずに外側の輪郭だけに縁を付けます。
- 太さやずらす量の px は、物の中心がカメラの既定の距離にあるときの大きさです。物が遠ざかると縁も細くなります。
- 「品質」は縁の丸さです。小さくすると多角形になります。「角縁取り」を入れると四角く広がります。
- 縁は影を落としません。
- 付けた物ごとに、その物をもう一度描いて輪郭を調べるので、そのぶん重くなります。

### 霧やもや（ノイズ3D）

図形の「ノイズ3D」を置くと、**幅・高さ・奥行きで決めた箱の中だけ**に霧が出ます。箱はアイテムの位置が中心で、「3D回転」で傾けられます。霧の中にある物は、手前の霧にだけ隠れます。

- 霧の量は「濃さ」、まだらの具合は「しきい値」で決めます。しきい値を上げるほど、ちぎれた雲のようになります。
- 「移動速度X/Y/Z」を入れると、模様が流れます。箱は動きません。
- 「ふちのぼかし」を上げると、箱の境目が目立たなくなります。
- 箱を薄い板の重なりで描いています。板の枚数はノイズの大きさに合わせて自動で減らし、「分割の細かさ」はその上限です。板の筋が見えるときは上げてください。
- 重さはおもに、画面に写る箱の広さで決まります。「繰り返し」の影響は小さめです。
- 種類かシード値を変えた直後だけ、ノイズを作り直すので一瞬止まります。
- 霧は YMM4 のレイヤー順で重なります。**物より上のレイヤーに置いてください。** 下に置くと、物の手前にある霧が物に隠れます。

### 3Dプレビュー

上の「追加」メニューから、カメラ・光源・環境を今の再生位置に置けます。

| 操作 | 効果 |
|---|---|
| 左ドラッグ | 回り込む |
| Shift + 左ドラッグ / 右ドラッグ | 平行移動 |
| Alt + 左ドラッグ | 傾ける |
| ホイール | 寄る・引く |
| アイテムをドラッグ | そのアイテムを動かす |
| Ctrl + ドラッグ | アイテムの上でも掴まず、選択も変えずに視点だけ動かす（Shift も押すと平行移動） |
| Ctrl + クリック | 複数選択に足す・外す |
| 右下の軸の先端をクリック | その軸の側から見る向きに切り替える（X で右から、Y で上から、Z で前から。短い側の先端はその反対側から） |
| 骨をクリック | 骨のあるモデルを選んでいるとき、その骨を選ぶ（骨の形のどこでも掴めます） |
| 骨の輪をドラッグ | 選んだ骨を、その軸まわりに回す |

アイテムを掴めるのは**絵が描かれているところだけ**です。透明な余白は素通しになり、後ろのアイテムを掴めます。

**骨のあるモデル**（VRM・FBX など）を選ぶと、骨が Blender と同じ**八面体の形**で出ます。骨のどこかをクリックするとその骨が選ばれ、**赤・緑・青の輪**が出ます。輪をドラッグすると、その軸まわりに回せます（赤が回転X、緑が回転Y、青が回転Z）。選んでいる骨の名前と親は、3Dプレビューの左下に出ます。回した値はアイテムのパラメータの「骨」に入るので、**プレビューからでもパラメータからでも同じ値を触れます**。動かした骨だけが並び、`K`（ドラッグで中間点を打つ）を入れておけば中間点も打たれます。骨ではないところを掴むと、これまでどおりアイテムごと動きます。

骨は**頭（回る中心）から尻尾（子の骨）へ**伸ばして描きます。子が 1 本だけならその子まで、子がいない骨や枝分かれする骨は短い出っ張りになります。ねじれ用の骨（`UpperArm_Twist_L` など）は関節と同じ場所から生えていて重なるので、**同じくらい近いときは関節の骨が選ばれます**。ねじれ用の骨は皮をひねるためのもので、回してもその先（肘から手など）はついてきません。腕ごと動かしたいときは、関節の骨（`UpperArm_L`、`LowerArm_L` など）を選んでください。

パラメータの「骨」は、**骨ごとに折りたためる形**で並びます。見出しがその骨の名前で、開くと回転X/Y/Z が出ます。見出しの右の `✕` を押すと、その骨の回転をやめられます。

| キー | 効果 |
|---|---|
| `F` | 選んだものに寄る |
| `Home` | 全体を見渡す |
| `1` / `Ctrl+1` | 前から / 後ろから |
| `3` / `Ctrl+3` | 右から / 左から |
| `7` / `Ctrl+7` | 上から / 下から |
| `Ctrl+R` | 視点をカメラに戻す |
| `Shift+R` | 傾きを戻す |
| `0` | カメラ追従の入切 |
| `K` | ドラッグで中間点を打つ、の入切 |
| `G` | グリッドの入切 |
| `S` | スナップの入切 |
| `Ctrl+A` | 出ているものをすべて選ぶ |
| `Esc` | 選択を外す |

**カメラ追従**を入れると、視点がカメラアイテムに追従し、ドラッグがそのカメラを直接動かします。外すと視点だけが動き、出力は変わりません。

入れたときにカメラアイテムが無ければ、**その場に1つ置いてから追従を始めます。** 複数ある区間では、**レイヤー番号がいちばん大きいもの**が動きます。撮っているカメラと同じ選び方です。

追従中にアイテムを掴んでしまうときは、`Ctrl` を押しながらドラッグしてください。カメラだけが動きます。

床のグリッドは「表示」メニューから消せます。

3Dプレビューを開くと、ymm4-info.net に最新のバージョンを1回だけ問い合わせます。新しいバージョンが公開されていれば、メニューの下に知らせが出ます。「×」で、YMM4 を閉じるまで隠せます。

選んでいるものを外すときは `Esc` を押すか、「編集」メニューの「選択を解除」を使ってください。何も無いところを押しても選択は外れないので、視点を動かしても選んだままです。

**複数選択**は `Ctrl` を押しながらのクリックです。押してから動かさずに離したときだけ選択が変わり、動かせば視点の操作になります。選んだものは、ドラッグするとまとめて動きます。軸ハンドルは選んだもの全部の真ん中に出ます。

**スナップ**（`S`）を入れると、動かした位置が決まった間隔に、回転が 15° ずつに吸い付きます。間隔は「編集」メニューで 10 / 50 / 100px から選べます。ドラッグ中に `Shift` を押している間だけ、入り切りが逆になります。

光源とカメラは、プレビュー上の目印を掴んで動かせます。平行光は原点のまわりに浮かぶ太陽、点光源は中心の球（外側の大きな球は届く距離を表すだけで、掴む場所ではありません）、スポットライトは光の届く範囲そのままの円錐、カメラは視野の枠の中どこでも掴めます。

選んでいる間は目印の場所に**軸ハンドル**が出ます。ふつうのアイテムと同じで、ハンドルを掴めばその軸だけに沿って動きます。

## 既知の制限

- **モデルのアニメーション・法線マップ・圧縮（Draco / meshopt）には対応していません。** 骨は読み込んで動かせますが、モデルに入っている動きは再生しません。
- **骨は 3Dプレビューとパラメータのどちらからでも動かせます。** 骨の名前で結びつけ、回転X/Y/Z を中間点で動かせます。親の骨を回すと子の骨もついて回ります（FK）。手足の先を引っぱって途中の骨を曲げる（IK）にはまだ対応していません。
- **fbx はバイナリ形式のみです。** テキスト形式で書き出されたものは読み込めません（書き出し時に「バイナリ」を選んでください）。テクスチャは、fbx に埋め込まれていればそれを使い、無ければファイル名をモデルのフォルダとその上・その下（2階層まで）から探します。
- **アイテムどうしの親子付けはできません。** まとめて動かしたいときは、グループ制御に入れてください。グループ制御の位置・Z・回転・拡大率は、中の 3D のアイテムに親として 3D のまま掛かります。**縦横の回転もしたいときは、グループ制御に「3D空間に置く」を付けてください**（下の「まとめて動かす」を参照）。グループ制御に入れられない組み合わせを連動させるときは、それぞれに同じ中間点を打ってください。
- **平面化した画素を加工するエフェクト**（グリッチノイズ、モザイクなど）は、3D図形アイテムの 3Dプレビューには現れません。動画出力には反映されます。
- **グループ制御に位置を変えるエフェクト**（カメラ位置・回り込み・登場退場など）を付けると、その中のアイテムは 3D から外れて板になります。標準プレビューと出力に合わせるためです。ぼかしや色調補正のように位置を変えないエフェクトなら、3D のままです。「縁取り3D」「3D空間に置く」などの 3D エフェクトをグループ制御に付けたときは、中のアイテムそれぞれに掛かり、3Dプレビューにも出ます。
- **「立体化3D」「湾曲3D」「波打ち3D」「折る3D」「砕け散る3D」をグループ制御に付けたとき**、中のアイテムがすでに 3D を持っていれば、その立体はそのまま残り、これらのエフェクトの形の変化は掛かりません（平らな絵に戻して押し出したり曲げたりはしません）。中のアイテムが 2D のときは、これまでどおり絵を板にして形を変えます。まとまり全体を動かしたいときは「3D空間に置く」を使ってください。
- **グループ制御に付けた 2D エフェクト**（ぼかし・エッジ抽出・回転など）は、**中の 3D のアイテムには 3Dプレビューで掛かりません。** 標準プレビューと動画出力では、3D で描いた後の絵に YMM4 が掛けるので反映されます。中の 2D のアイテム（板として表示されるもの）には、3Dプレビューでも掛かります。
- **下のレイヤーをまとめて1枚にするアイテム**（エフェクトアイテム、グループ制御、画面の複製、シーンチェンジ）は、3Dプレビューには出ません。動画出力には反映されます。3Dプレビューは合成前のアイテムを1つずつ並べて描くので、まとめた絵を重ねると同じものが二重に写るためです。
  - ただし、**「画像を合成」を入れたグループ制御と画面の複製に「3D空間に置く」などの3Dエフェクトを付けたとき**は、3Dプレビューにもその1枚が出ます。「画像を合成」のグループでは、中のアイテムは別には描かず、グループの板にまとめて写ります。
  - まとめる側とまとめられる側は、互いを隠したり影を落としたりしません。
- **立体化するエフェクトは、カメラ系エフェクト（回り込みカメラなど）より後ろに置いてください。** 逆に置くと、動画出力では立体を描いた絵が 2D で歪み、3Dプレビューと一致しなくなります。
- アイテムをまたいだ前後関係のために、各アイテムを描くたびにほかの 3D アイテムを確かめます。その絵に写らない物は描かずに飛ばしますが、確かめる手間は **3D アイテムの数の 2 乗**に比例するので、数十個を超えると重くなります。
