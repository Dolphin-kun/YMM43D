# YMM43D

ゆっくりMovieMaker4 に 3D 空間を足すプラグインです。

図形・エフェクト・アイテムのすべてが 1 つのワールド座標に並ぶので、**アイテムをまたいだ前後関係が正しく出ます**。上のレイヤーが必ず手前になる、ということがありません。

カメラ・光源・環境はタイムライン上のアイテムとして置きます。ふつうのアイテムと同じように中間点を打てるので、値を時間で動かせます。

## 追加されるもの

### 図形

| 名前 | 内容 |
|---|---|
| 3Dアイテム | 平面・正多面体5種（四〜二十面体）・球・円柱・円錐・ドーナツ。面ごとの塗り分けができます |

### 映像エフェクト

| 名前 | 内容 |
|---|---|
| 3D空間に置く | ふつうの 2D アイテムを板として 3D 空間に置きます。3軸の回転も掛かります |
| 立体化3D | 画像の形をそのまま奥行き方向へ押し出します |
| 点群3D | 画像を格子状の粒・線・面に分解します。波・ねじれ・膨らみ・球への巻き付けができます |

### タイムラインアイテム

| 名前 | 内容 |
|---|---|
| 3Dカメラ | 位置と向き。置いた区間だけ効き、レイヤー番号がいちばん大きいものが使われます |
| 3D光源 | 平行光と点光源。置いた分だけ足し合わさります（4灯まで） |
| 3D環境 | 環境光と霧。レイヤー番号がいちばん大きいものが使われます |

### ツールウィンドウ

**3Dプレビュー**。シーンを好きな視点から確認でき、アイテムを直接掴んで動かせます。

## 使い方

### 2D のアイテムをカメラに乗せる

テキストや画像は YMM4 が 2D のまま描くので、そのままではカメラの影響を受けません。**「3D空間に置く」を付けると、他の 3D 物体と同じ扱いになります。**

まとめて乗せたいときは、**エフェクトアイテム**に付けてください。下のレイヤーを合成した絵に掛かるので、1 つ置くだけでその下すべてが 1 枚の板としてカメラに乗ります（そのかわり、アイテムごとの前後関係は失われます）。**この乗せ方は動画出力にだけ現れます。** 3Dプレビューは合成前のアイテムを1つずつ描くので、そちらではアイテムが別々に見えます。

アイテムの種類ごとに既定にすることもできます。エフェクトを付けたアイテムを YMM4 の「デフォルトのアイテム」として保存すると、以後その種類の新しいアイテムに最初から付きます。

### カメラ

カメラアイテムが無い区間は、原点を正面から見る既定のカメラになります。

画角は既定では、**カメラから 1000px 離れた面が画面とちょうど 1 対 1 で写るように**決まります。このため既定の位置に置いたカメラでは、Z = 0 のアイテムが YMM4 の 2D と同じ位置・大きさに写ります。「視野角変更」を入れると自分で決められます。

置き方は3つあります。

| 置き方 | 決め方 | 向いている使い方 |
|---|---|---|
| **注目**（既定） | 置く場所 + 見つめる点 | 被写体を追う |
| 位置 | 置く場所 + 水平・垂直の回転角 | カメラを手で持つように振る |
| 回り込み | 見つめる点 + 距離 + 水平・垂直の回転角 | 被写体のまわりを回す |

**「回り込み」は、YMM4 の「回り込みカメラ」と同じ決め方です。** ただしこちらは本物の 3D 空間のカメラなので、3D の図形もエフェクトも 2D のアイテムも、まとめて正しい前後関係のまま回り込みます。中間点を打てば、距離や角度を時間で動かせます。

### 光

光源アイテムを 1 つも置かなければ、**左上手前からの平行光と環境光**が当たります。この既定値は、カメラを正面から向いた面がちょうど明るさ 1 になるように選んであります。2D の絵を「3D空間に置く」だけのときに暗くならないためです。

陰影を掛けたくないものは、各エフェクトと図形の「陰影をつけない」を入れてください。

### 3Dプレビュー

上の「追加」メニューから、カメラ・光源・環境を今の再生位置に置けます。

| 操作 | 効果 |
|---|---|
| 左ドラッグ | 回り込む |
| Shift + 左ドラッグ / 右ドラッグ | 平行移動 |
| Ctrl + 左ドラッグ | 傾ける |
| ホイール | 寄る・引く |
| アイテムをドラッグ | そのアイテムを動かす |
| Alt + ドラッグ | アイテムを掴まず、視点だけ動かす |

アイテムを掴めるのは**絵が描かれているところだけ**です。透明な余白は素通しになり、後ろのアイテムを掴めます。

| キー | 効果 |
|---|---|
| `F` | 選んだものに寄る |
| `Home` | 全体を見渡す |
| `1` / `Ctrl+1` | 前から / 後ろから |
| `3` / `Ctrl+3` | 右から / 左から |
| `7` / `Ctrl+7` | 上から / 下から |
| `Ctrl+R` | 視点をカメラに戻す |
| `Shift+R` | 傾きを戻す |
| `0` | カメラ追従の入切 |
| `K` | ドラッグで中間点を打つ、の入切 |
| `G` | グリッドの入切 |
| `Esc` | 選択を外す |

**カメラ追従**を入れると、視点がカメラアイテムに追従し、ドラッグがそのカメラを直接動かします。外すと視点だけが動き、出力は変わりません。

入れたときにカメラアイテムが無ければ、**その場に1つ置いてから追従を始めます。** 複数ある区間では、**レイヤー番号がいちばん大きいもの**が動きます。撮っているカメラと同じ選び方です。

追従中にアイテムを掴んでしまうときは、`Alt` を押しながらドラッグしてください。カメラだけが動きます。

床のグリッドは「表示」メニューから消せます。

選んでいるものを外すときは、何も無いところを押すか `Esc` を押してください。

光源とカメラは、プレビュー上の目印を掴んで動かせます。平行光は原点のまわりに浮かぶ太陽、点光源は中心の球（外側の大きな球は届く距離を表すだけで、掴む場所ではありません）、カメラは視野の枠の中どこでも掴めます。

選んでいる間は目印の場所に**軸ハンドル**が出ます。ふつうのアイテムと同じで、ハンドルを掴めばその軸だけに沿って動きます。

## 既知の制限

- **影は落ちません。** 光は当たりますが、遮蔽は計算していません。
- **`.obj` などのモデルは読み込めません。** 形は図形アイテムに用意されたものだけです。
- **親子付けはできません。** アイテムどうしを連動させるには、それぞれに同じ中間点を打ってください。
- **平面化した画素を加工するエフェクト**（グリッチノイズ、モザイクなど）は、3D図形アイテムの 3Dプレビューには現れません。動画出力には反映されます。
- **下のレイヤーをまとめて1枚にするアイテム**（エフェクトアイテム、グループ制御、フレームバッファ、シーンチェンジ）は、3Dプレビューには出ません。動画出力には反映されます。3Dプレビューは合成前のアイテムを1つずつ並べて描くので、まとめた絵を重ねると同じものが二重に写るためです。
- **立体化するエフェクトは、カメラ系エフェクト（回り込みカメラなど）より後ろに置いてください。** 逆に置くと、動画出力では立体を描いた絵が 2D で歪み、3Dプレビューと一致しなくなります。
- アイテムをまたいだ前後関係の計算量は、**3D アイテムの数の 2 乗**に比例します。数十個を超えると重くなります。
