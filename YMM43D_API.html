InterfaceNamespace: YMM43D.Rendering

プロパティ
TypeNameDescription
bool RequiresMappedTexture 3D描画の際、元の2Dテクスチャ（画像の生データなど）を必要とする場合は true を返します。 エフェクト等では通常 true、単純な3D形状モデル（テクスチャ不要なもの）では false を指定します。
メソッド
Return TypeSignatureDescription

DrawContext3D
StructNamespace: YMM43D.Rendering
各オブジェクトを3D描画する際に、マッパーによって収集された座標情報や不透明度、適用テクスチャなどのパラメータを格納するデータ構造です（未使用パラメータが整理されました）。
プロパティ
TypeNameDescription
Matrix4x4 World 合成済みの3Dオブジェクト用ワールド変換行列（位置・回転・スケール）。
float Opacity 0.0 (透明) ～ 1.0 (不透明) の描画不透明度。
Blend Blend YMM4の合成モード（Normal、Add、Multiply、Subtract、Screen）。
bool IsAlwaysOnTop true の場合、深度テストを無効にして他の3Dオブジェクトより常に手前に描画します。
ID3D11ShaderResourceView? Texture RequiresMappedTexture が true の場合に渡される、描画ソース用のテクスチャ（SRV）。
bool OwnsTexture 描画終了後に呼び出し側でテクスチャリソースを自動的に Dispose するかどうかの制御フラグ。
int Frame アイテムの現在の再生フレーム。
int Length アイテムの総フレーム数。
int FPS 再生中のプロジェクトのFPS。
ソースコード定義
public class DrawContext3D

SceneCamera
ClassNamespace: YMM43D.Preview
3D空間内のカメラ設定（水平・垂直・ロール回転、距離、注視点座標）を管理するクラスです。 シングルトンが廃止され、完全にインスタンス化可能になりました。 タイムラインやプレビュー環境ごとに GetCamera(key) を通じて固有のインスタンスを取得し、描画パスごとの干渉を完全に防ぎます。
プロパティ
TypeNameDescription

Animation CameraDistance 注視点からカメラまでの距離のアニメーション情報。
Vector3 CameraTarget カメラが向き続ける注視点の3D座標。
静的メソッド
Return TypeSignatureDescription
static SceneCamera GetCamera(object? key) タイムラインやデバイスなどをキーとして、そのコンテキストに紐付けられた固有の `SceneCamera` を取得します。複数プレビュー時の干渉を防ぎます。
